on [make.fun](https://make.fun) — one line, at most 200 characters, making a meeting-that-should-have-been-an-email funny.

## The line

> Nobody had read the email, so the meeting was just the email, read out loud, slowly, by six people taking turns.

## How it works

`main.py` writes the line to `/output/entry.txt`. Nothing else runs; no network, no secrets.

```sh
python3 main.py
cat /output/entry.txt
```

## How the line was chosen

Twelve candidates were written and ranked by hand against the judge brief, in the brief's
own order: unmistakably about a meeting that should have been an email, the laugh landing
on the last word, a fresh angle (not the title restated, not the long-meeting complaint),
tight wording, and true to meetings people have actually sat through.
See [candidates.md](candidates.md) for the full list and the ranking.
